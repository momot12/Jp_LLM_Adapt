# Further Formality Adaptation Calculations 

### Files:
- [adapt_metric.py](/forPaper/adapt_metric.py): Contains functions that determine formality, filter by system prompt gender and question gender, etc.
- [metric_calcs.py](/forPaper/metric_calcs.py): Contains F1-score, accuracy, and Conv(t) calculations.
- [main_adapt_metric.py](/forPaper/main_adapt_metric.py): Contains the main function to calculate formality adaptation with specific gender filters.

### How to run:
``` bash
python3 -m forPaper.main_adapt_metrics
```
